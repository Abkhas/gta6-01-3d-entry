# Palma Verde — Make GTA 6 (gta6-01)

An original open-world crime game in a desktop browser, built for the
[make.fun](https://make.fun) bounty **gta6-01 "Make GTA 6"**.

Palma Verde is a sun-belt bay city. You are Rey Calder, ex-getaway driver,
working off a $2,000 debt to fixer Nadia Venn — 10 story missions, a
3-person crew, 5-star wanted heat with PVPD dispatch and a police heli,
a garage, properties, and a full-city map.

Play: serve this directory over HTTP (for example `python3 -m http.server`)
and open `game/index.html` in a desktop browser. Keyboard + mouse.

Built from scratch for gta6-01. All code, names, story, and art are original.
